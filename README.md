# Java Racing Car Precourse 요약

## 전제조건
- 자동차 이름은 **알파벳과 숫자만** 허용
  - ✅ 예: `a2`, `pop`
  - ❌ 예: `w;pop`, `slw!`

---

## 1️⃣ 입력 처리(InputView)
- 자동차 이름 입력
- 라운드 횟수 입력

---

## 2️⃣ 입력 검증

### 자동차 이름 검증
- 허용 문자: 알파벳, 숫자, `,`
- 조건
  1. `,`로 시작하면 ❌ 예외
  2. 이름 중 하나라도 6자 이상 ❌ 예외
  3. 허용 문자 이외 포함 ❌ 예외
  4. 모든 이름 5자 이하 → ✅ 통과

### 라운드 횟수 검증
- 숫자가 아니면 ❌ 예외
- 정수일 경우 → ✅ 통과

---

## 3️⃣ 자동차 객체
- 각 자동차는 `move()` 메서드로 전진 여부 판단
- 랜덤값(`0~9`)이 **4 이상이면 전진**

---

## 4️⃣ 레이싱 객체
- 각 라운드마다 모든 자동차 이동 수행
- 모든 라운드 종료 후 **우승자 선정**

---

## 5️⃣ 출력(RacingView)
- 각 라운드 자동차 이름과 이동 거리 출력
- 최종 우승자 이름 출력

---
## 6️⃣ 레이싱 Service 객체(RacingService)
- 레이싱 객체와 RacingView를 이용해 레이싱 진행

## 7️⃣ Controller
- InputView로 입력값 수집
- RacingService 객체 생성 후 레이싱 진행
- RacingView 통해 결과 출력
